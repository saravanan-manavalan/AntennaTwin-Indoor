# V0.3.3 Verification and Validation

V0.3.3 introduces deterministic checks for the core analytical components.

## 1. Free-space path loss

The implementation is verified against:

\[
FSPL = 20\log_{10}(4\pi d f/c)
\]

with distance `d`, frequency `f`, and speed of light `c`.

## 2. Wall attenuation

A ray crossing one wall receives the configured wall loss. A ray whose intersection lies within a configured opening receives no loss from that wall.

## 3. Directional antenna

The analytic pattern is checked at boresight and at half the 3-dB beamwidth. The half-beamwidth point must be 3 dB below peak gain.

## 4. Coverage

Coverage percentage is independently checked against a small deterministic RSSI array.

## 5. Optimizer

The end-to-end regression test checks that the optimizer returns a physically bounded position, valid azimuth, and coverage in [0, 100].

## Scope limitation

These tests verify software implementation and internal consistency. They do not constitute experimental validation against measured indoor channel data or full-wave/ray-tracing simulation. Such independent validation should be added before claiming external predictive accuracy in a SoftwareX manuscript.


## V0.3.3 physical-feasibility verification

V0.3.3 additionally verifies that the optimizer does not select candidate
antenna positions within the configured minimum clearance of internal wall
segments. The default clearance is 0.5 m. This is enforced as a geometric
feasibility condition rather than a coverage or RSSI penalty.


## V0.3.4 demonstration scenario

The challenging demonstration is intended to exercise the software under
more restrictive propagation conditions than the default example. It contains
two concrete partitions with finite openings and compares a fixed room-centre
baseline against the constrained joint position/orientation optimizer.
